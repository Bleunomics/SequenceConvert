Check the kind of VCF you have

A .snp-indel.genome.vcf.gz file may contain SNP calls, indels, and gVCF reference blocks. Only explicit SNP calls with rsIDs are usable here; indels and reference blocks are skipped. A .sv.vcf.gz file alone usually contains structural variants, not ancestry SNPs. If rsIDs are absent, request a dbSNP-annotated SNP / small-variant VCF from your sequencing provider.

This converter does not call variants, look up rsIDs, impute DNA, or treat unlisted sites as reference calls. GRCh38 SNPs can be lifted to hg19 locally using reference files you select below. A correctly formatted file is not a guarantee that ExploreYourDNA or its report tools will accept it or have enough overlapping markers.

Local GRCh38-to-hg19 liftover

Download these public reference resources yourself (no DNA is sent). Then select your local copies. No reference files are bundled.

  1. UCSC hg38ToHg19.over.chain.gz (check the UCSC chain terms).
  2. UCSC hg19.fa.gz reference. Select hg19.fa.gz directly, or an already extracted hg19.fa.

Compressed references are streamed into temporary, disk-backed browser storage before indexing. Allow several GB of free storage and use current Chrome or Edge with site storage enabled. The temporary reference is removed after conversion, errors, or cancellation. No DNA is stored there. If storage is unavailable, extract .fa.gz yourself and select .fa instead.

If no .fai is selected, the app builds one locally by scanning the reference once; this may take several minutes. A save-index link will appear for reuse. After indexing, only small reference regions are read. The entire FASTA is never loaded into memory.

A supplied .fai must describe the exact decompressed FASTA, not compressed byte offsets. Each conversion decompresses the reference again. After an abrupt browser shutdown, clear this page's site storage to reclaim any leftover temporary reference.

Only uniquely mapped, same-chromosome SNPs with matching target REF bases are exported. Reverse-strand alleles are complemented. Ambiguous, unmapped, cross-chromosome and reference-mismatching sites are skipped and counted. MT is excluded from liftover because UCSC hg19's mitochondrial reference differs from GRCh37/rCRS. This does not annotate missing rsIDs or recreate a SNP chip.
